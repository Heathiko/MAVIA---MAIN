## Required links (8)

- organ_system -> systems_table: the table lists organ systems and their organs, so the learner must first know that an organ system is a group of organs doing one big job.
- systems_table -> heart_lungs_teamwork: the heart-and-lungs loop joins the respiratory and circulatory systems, so the learner needs to know what each system's organs do.
- systems_table -> food_energy_teamwork: the food path shows the digestive, circulatory and urinary systems working as one team.
- systems_table -> brain_teamwork: the brain sends messages to muscles, heart and lungs, so the learner needs to know the systems those organs belong to and what they do.
- systems_table -> bones_muscles_teamwork: bones and muscles working together is the skeletal and muscular systems teaming up, which the table introduces with their jobs.
- heart_lungs_teamwork -> organ_problems: smoke-damaged lungs making the heart work harder, and a stopped heart starving the brain of oxygen, only make sense after the heart-and-lungs teamwork.
- food_energy_teamwork -> organ_problems: nutrients failing to reach organs, and waste staying in the blood when the kidneys fail, build on how nutrients travel and how the kidneys clean the blood.
- organ_problems -> organ_care: the healthy habits are given as "this is why" we care for all organs, which follows from seeing how one sick organ harms the others.
